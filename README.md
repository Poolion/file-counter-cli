# file-counter-cli

A small Python CLI that counts files in a directory, optionally filtered by extension.

## Usage

```bash
python file_counter.py /path/to/directory --ext .py
```

## Install

```bash
git clone https://github.com/Poolion/file-counter-cli.git
cd file-counter-cli
python file_counter.py .
```
